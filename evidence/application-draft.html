Scope

The local Careers page previously linked to official listings. It now includes role/application previews based on the audited roles. Actual job availability and full descriptions remain on the official careers site.

Drafts are kept only while this page stays open. A confirmed reload or departure clears them; nothing is written to browser storage. The local application test sends no network request and uploads no file. Production remains unchanged; nothing was deployed.

Tests used isolated Chromium, synthetic applicant details, and an in-memory PDF fixture. No real application, résumé upload, or account creation occurred.
